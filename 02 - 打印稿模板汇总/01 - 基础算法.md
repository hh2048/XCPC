### 常用函数

#### 精确开平方

兼容 `long long`、`__int128` 类型。注意自带 `sqrt` 无法精确计算长整型（易错）。

```c++
template<class T> T isqrt(T n) { // n >= 0
    T x = sqrtl(n); // 如不需要兼容 `__int128`，可使用 `sqrt` 代替，常数略小一点
    while (x + 1 <= n / (x + 1)) ++x;
    while (x && x > n / x) --x;
    return x;
}
```

#### 对数

兼容 `__int128` 类型。

```c++
// `long long` 时等价 63 - __builtin_clzll(n)
// `int` 时等价 31 - __builtin_clz(n)
template<class T> int log2floor(T n) { // n > 0
    int r = -1;
    while (n) ++r, n >>= 1;
    return r;
}

// `int` 时等价 31 - __builtin_clz(n) + (__builtin_popcount(n) != 1)
template<class T> int log2ceil(T n) { // n > 0
    return log2floor(n) + ((n & (n - 1)) != 0);
}
```

#### 取整

```c++
template<class T> T sign(T x) {
    return (x > 0) - (x < 0);
}

template<class T> T floor(T a, T b) { // b != 0
    T A = a / b, B = a % b;
    return A - (B && ((B < 0) != (b < 0)));
}

template<class T> T ceil(T a, T b) { // b != 0
    T A = a / b, B = a % b;
    return A + (B && ((B < 0) == (b < 0)));
}
```

### 整数域二分

#### 库函数

在使用前需要**先进行排序**，以下是默认升序的写法。

`lower_bound` 和 `upper_bound` 返回首个 $\geq x$ 和 $> x$ 的迭代器。

```c++
vector<int> a = {1, 3, 3, 5};
int x = 3;
auto L_itr = lower_bound(a.begin(), a.end(), x); // 首个 >= x 的迭代器
auto R_itr = upper_bound(a.begin(), a.end(), x); // 首个 > x 的迭代器

auto L_idx = L_itr - a.begin(); // 下标：1
auto R_idx = R_itr - a.begin(); // 下标：3

auto count_x = R_itr - L_itr; // x 在 a 中出现的次数：2

if (L_itr != a.end()) {
    auto L_val = *L_itr; // 首个 >= x 的值：3
}
if (R_itr != a.end()) {
    auto R_val = *R_itr; // 首个 > x 的值：5
}
```

#### 目标或目标后继

闭区间 $[l, r]$ 内，`judge(x)` 随 $x$ 增大从 `false` 单调变为 `true`，**且存在 `true`**。返回值为首个 `true` 的位置。

```c++
// assert(judge(r)); // 还能不存在，是不是题错了？
while (l < r) {
    i64 mid = l + (r - l) / 2;
    if (judge(mid)) r = mid;
    else l = mid + 1;
}
return l;
```

#### 目标或目标前驱

闭区间 $[l, r]$ 内，`judge(x)` 随 $x$ 增大从 `true` 单调变为 `false`，**且存在 `true`**。返回值为最后一个 `true` 的位置。

```c++
// assert(judge(l)); // 还能不存在，是不是题错了？
while (l < r) {
    i64 mid = l + (r - l + 1) / 2;
    if (judge(mid)) l = mid;
    else r = mid - 1;
}
return l;
```

### 实数域二分

闭区间 $[l, r]$ 内，满足：

- `judge(l) = false`、`judge(r) = true`；
- `judge(x)` 随 $x$ 增大从 `false` 单调变为 `true`。

返回值为 `false` 侧近似值，`true` 侧近似值。

```c++
// 限制次数能很好的平衡精度和速度，不要使用 `EPS` 的写法
for (int t = 1; t <= 100; t++) {
    f64 mid = (l + r) / 2;
    if (judge(mid)) r = mid;
    else l = mid;
}
return l;
```

### 整数域三分

闭区间 $[l, r]$ 内，`check(x)` 为单谷函数；返回值为最小值所在的位置（成段时返回最左端）。

```c++
while (l < r) {
    i64 mid = l + (r - l) / 2;
    if (check(mid) <= check(mid + 1)) r = mid;
    else l = mid + 1;
}
return l;
```

### 实数域三分

闭区间 $[l, r]$ 内，`check(x)` 为单谷函数；返回值为最小值点的近似位置。

```c++
// 限制次数能很好的平衡精度和速度，不要使用 `EPS` 的写法
for (int t = 1; t <= 100; t++) {
    f64 mid1 = (l * 2 + r) / 3;
    f64 mid2 = (l + r * 2) / 3;
    if (check(mid1) < check(mid2)) {
        r = mid2;
    } else {
        l = mid1;
    }
}
return l;
```
